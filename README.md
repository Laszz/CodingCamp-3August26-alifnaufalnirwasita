# 💸 Spendly — Expense & Budget Visualizer

A modern, mobile-first expense tracking web application built with **HTML**, **CSS**, and **Vanilla JavaScript** for the CodingCamp Software Engineering Project.

## ✨ Features

### 📊 Dashboard
- View total expenses
- Monthly spending summary
- Recent transactions
- Quick expense input

### ➕ Expense Management
- Add new expenses
- Delete transactions
- Form validation
- Automatic total updates

### 📈 Analytics
- Interactive Doughnut Chart using Chart.js
- Spending breakdown by category
- Real-time updates

### 📜 Transaction History
- View all transactions
- Search transactions
- Sort transactions

### ⚙️ Settings
- Dark / Light Mode
- Clear all data
- Local Storage persistence
